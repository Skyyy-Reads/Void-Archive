⚙ Connect to Supabase
One-time setup — paste your Supabase credentials to connect your shared database. Do this once and your site will work for everyone.
1
Go to supabase.com, create a free account, then click New Project.
2
Once your project is ready, go to Project Settings → API and copy your Project URL and anon public key.
3
Go to SQL Editor and run this to create the tables:
CREATE TABLE posts ( id bigint generated always as identity primary key, type text not null, author text not null, title text, body text, link text, image_url text, pinned boolean default false, edited boolean default false, likes int default 0, created_at timestamptz default now() ); CREATE TABLE announcements ( id bigint generated always as identity primary key, title text, body text, edited boolean default false, created_at timestamptz default now() ); CREATE TABLE users ( id bigint generated always as identity primary key, username text unique not null, password text not null, approved boolean default false, bio text default '', created_at timestamptz default now() ); ALTER TABLE posts ENABLE ROW LEVEL SECURITY; ALTER TABLE announcements ENABLE ROW LEVEL SECURITY; ALTER TABLE users ENABLE ROW LEVEL SECURITY; CREATE POLICY "public read posts" ON posts FOR SELECT USING (true); CREATE POLICY "public insert posts" ON posts FOR INSERT WITH CHECK (true); CREATE POLICY "public update posts" ON posts FOR UPDATE USING (true); CREATE POLICY "public delete posts" ON posts FOR DELETE USING (true); CREATE POLICY "public read ann" ON announcements FOR SELECT USING (true); CREATE POLICY "public insert ann" ON announcements FOR INSERT WITH CHECK (true); CREATE POLICY "public update ann" ON announcements FOR UPDATE USING (true); CREATE POLICY "public delete ann" ON announcements FOR DELETE USING (true); CREATE POLICY "public read users" ON users FOR SELECT USING (true); CREATE POLICY "public insert users" ON users FOR INSERT WITH CHECK (true); CREATE POLICY "public update users" ON users FOR UPDATE USING (true); CREATE POLICY "public delete users" ON users FOR DELETE USING (true);
4
Go to Storage, create a public bucket called images. Under bucket settings set it to Public.
